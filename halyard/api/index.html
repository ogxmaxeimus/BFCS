API

One API, every market.

REST for state, WebSocket for the tape, SDKs for the rest. The same prices and the same fees as the app, with keys you can scope to read, trade or withdraw.

const ws = new WebSocket("wss://stream.halyard.exchange/v1")
ws.onopen = () => ws.send(JSON.stringify({
  op: "subscribe", channel: "ticker", pairs: ["BTC-USD", "ETH-USD"]
}))
ws.onmessage = (m) => {
  const t = JSON.parse(m.data)   // { pair, last, bid, ask, ts }
  render(t)
}

book = hy.orderbook("BTC-USD", depth=16)
